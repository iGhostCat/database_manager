# vacancy_search
Учебный проект программы, которая позволяет получать информацию о вакансиях с платформы hh.ru в России, сохранять ее в файл и позволять удобно работать с ней: добавлять, фильтровать, удалять.

## Установка:

1. Клонируйте репозиторий: 
```
git clone https://github.com/iGhostCat/oop_lessons.git
```

2. Разверните виртуальное окружение проекта:
```
pip install poetry
poetry shell
```
3. Проведите тестирование корректности работы представленного функционала:
```
pytest
```
